# TINTORO - K-Beauty Wholesale Distribution Platform

Professional wholesale distribution platform for K-Beauty and cosmetics, powered by TELICA electronic shelf label technology.

## 🏪 About TINTORO

TINTORO is an authorized reseller and distributor of:
- **TELICA Electronic Shelf Labels (ESL)** - Advanced digital price display solutions
- **CREBEE Platform Solutions** - Integrated retail management systems
- **K-Beauty & Cosmetics** - Premium Korean beauty product wholesale

### Key Features
- ✅ B2B wholesale distribution for authorized retailers
- ✅ TELICA ESL integration and support
- ✅ POS system compatibility (Square, Shopify, etc.)
- ✅ Global supply chain expertise
- ✅ K-Beauty specialty products
- ✅ Comprehensive catalog management

## 🚀 Deployment

The site is automatically deployed to Cloudflare Pages whenever changes are pushed to the `main` branch in GitHub.

### Deployment Process
1. Make changes locally
2. Commit to GitHub: `git commit -m "your message"`
3. Push to main: `git push origin main`
4. Cloudflare automatically deploys (1-2 minutes)
5. Visit https://tintotoshop.com to see changes
